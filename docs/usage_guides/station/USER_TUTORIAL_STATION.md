# Tutoriel Station - Guide visuel pas à pas (fidèle à l'écran)

Objectif: gérer la station sans hésiter sur l'emplacement des actions.

## 0) Comment lire l'écran station
- À gauche: menu latéral (sidebar).
- En haut: barre supérieure avec cloche `Notifications`.
- Élément actif dans le menu: fond doré (`#DDAF3B`) avec texte foncé.

---

## 1) Se connecter

### Où regarder
- Centre de la page de connexion station.

### À quoi ça ressemble
- Formulaire + bouton principal `Se connecter`.

### Quoi cliquer
1. Saisissez vos identifiants.
2. Cliquez `Se connecter`.

### Confirmation que ça marche
- Vous arrivez sur l'espace station avec le menu latéral à gauche.

---

## 2) Comprendre le menu de gauche

### Où regarder
- Sidebar gauche.

### À quoi ça ressemble
Vous voyez les sections:
- `Opérations`
- `Configuration`
- `Support & Historique`

Et les pages:
- `Accueil`
- `File d'attente`
- `Réservations`
- `Retards`
- `Analytique`
- `Services`
- `Disponibilité`
- `QR Code`
- `Paramètres`
- `Historique`
- `Support`

### Quoi cliquer
- Cliquez un item dans la sidebar.

### Confirmation que ça marche
- L'item sélectionné devient visuellement actif (fond doré).
- Le contenu principal (à droite) change.

---

## 3) Opérations quotidiennes

### Où regarder
- Section `Opérations` dans la sidebar.

### Quoi cliquer
1. `File d'attente` pour gérer l'ordre des clients.
2. `Réservations` pour les rendez-vous.
3. `Retards` pour les demandes de retard.
4. `Analytique` pour les indicateurs.

### Confirmation que ça marche
- Chaque page affiche son propre contenu au centre/droite.

---

## 4) Configuration

### Où regarder
- Section `Configuration` dans la sidebar.

### Quoi cliquer
1. `Services` pour gérer services/formats/extras.
2. `Disponibilité` pour horaires et créneaux.
3. `QR Code` pour l'identité QR station.
4. `Paramètres` pour les réglages globaux de la station.

### Confirmation que ça marche
- Le titre/contenu de page change selon le menu choisi.

---

## 5) Connecter Stripe (important)

### Où regarder
1. Sidebar gauche -> `Paramètres`.
2. Dans la page, onglet `Paiements`.

### À quoi ça ressemble
- Carte Stripe avec titre `Connexion Stripe`.
- Bouton bleu Stripe: `Connecter avec Stripe` (si non connecté).

### Quoi cliquer
1. Cliquez `Connecter avec Stripe`.
2. Suivez le parcours Stripe.
3. Revenez sur la page `Paiements`.

### Confirmation que ça marche
- Le statut évolue vers actif (badge d'état visible dans la carte Stripe).

---

## 6) Support

### Où regarder
- Sidebar -> `Support`.

### À quoi ça ressemble
- Titre `Support`.
- Bouton `Nouveau ticket` en haut de la zone.
- Formulaire ticket avec `Sujet`, `Message`.
- En bas à droite du formulaire: `Envoyer` (doré).

### Quoi cliquer
1. Cliquez `Nouveau ticket`.
2. Remplissez `Sujet`.
3. Remplissez `Message`.
4. Cliquez `Envoyer`.

### Confirmation que ça marche
- Message de succès ticket.
- Le ticket apparaît dans la liste.

---

## 7) Notifications

### Où regarder
- En haut à droite: cloche `Notifications`.

### À quoi ça ressemble
- Panneau notifications avec action `Tout marquer lu`.

### Quoi cliquer
1. Cliquez la cloche.
2. Cliquez `Tout marquer lu`.

### Confirmation que ça marche
- Les notifications passent en lu.
