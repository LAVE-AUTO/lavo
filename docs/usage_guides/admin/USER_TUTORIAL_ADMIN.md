# Tutoriel Admin - Guide visuel pas à pas (fidèle à l'écran)

Objectif: naviguer dans la console admin en sachant exactement où cliquer.

## 0) Comment lire l'écran admin
- À gauche: sidebar de pilotage.
- En haut: barre supérieure avec cloche `Notifications`.
- Élément actif dans la sidebar: fond doré (`#DDAF3B`).

---

## 1) Se connecter

### Où regarder
- Centre de la page admin.

### À quoi ça ressemble
- Formulaire login + bouton `Se connecter`.

### Quoi cliquer
1. Saisissez vos identifiants.
2. Cliquez `Se connecter`.

### Confirmation que ça marche
- Vous arrivez sur `Tableau de bord`.

---

## 2) Comprendre le menu de gauche

### Où regarder
- Sidebar admin.

### À quoi ça ressemble
Sections:
- `Opérations`
- `Configuration`
- `Support & Historique`

Pages visibles:
- `Tableau de bord`
- `Validation KYC`
- `Litiges`
- `Comptes`
- `Commission`
- `Paramètres`
- `Transactions`
- `Journaux`
- `Avis`
- `Support`
- `Contenu légal`

En bas:
- `Mon profil`
- `Déconnexion`

### Quoi cliquer
- Cliquez une entrée de la sidebar.

### Confirmation que ça marche
- L'entrée prend le style actif (fond doré).
- Le contenu principal se met à jour.

---

## 3) Parcours opérationnel recommandé

### Étape A - Validation station
1. Sidebar -> `Validation KYC`.
2. Ouvrez un dossier station.
3. Utilisez les actions visibles dans la fiche (approbation/rejet selon le cas).

### Étape B - Litiges
1. Sidebar -> `Litiges`.
2. Ouvrez un litige.
3. Choisissez l'action disponible dans l'écran.

### Étape C - Comptes
1. Sidebar -> `Comptes`.
2. Recherchez et ouvrez une fiche.

### Confirmation que ça marche
- Après chaque action, l'état affiché de l'élément change (statut/ligne/fiche).

---

## 4) Configuration plateforme

### Où regarder
- Section `Configuration` de la sidebar.

### Quoi cliquer
1. `Commission` pour les règles de commission.
2. `Paramètres` pour les paramètres plateforme.

### Confirmation que ça marche
- Le formulaire de la page concernée s'affiche.
- Le bouton de sauvegarde confirme l'enregistrement.

---

## 5) Contrôle, support et conformité

### Où regarder
- Section `Support & Historique`.

### Quoi cliquer
1. `Transactions` pour le suivi des flux.
2. `Journaux` pour la traçabilité.
3. `Avis` pour modération.
4. `Support` pour tickets.
5. `Contenu légal` pour les pages légales.

### Confirmation que ça marche
- Chaque module ouvre sa vue dédiée.
- Les filtres/actions de la page répondent dans le contenu principal.

---

## 6) Profil et notifications

### Profil
1. En bas de la sidebar, cliquez `Mon profil`.
2. Modifiez les informations.
3. Sauvegardez.

### Notifications
1. En haut à droite, cliquez la cloche `Notifications`.
2. Cliquez `Tout marquer lu` si nécessaire.

### Confirmation que ça marche
- Profil: message de succès après sauvegarde.
- Notifications: compteur non lu diminue/disparaît.
